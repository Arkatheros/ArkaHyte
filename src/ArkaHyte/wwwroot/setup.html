ARKA HYTE Configuration

Écran du boîtier

Arka Hyte s'affiche sur l'écran tactile du boîtier, reconnu à sa taille. Sélectionnez-le ci-dessous (en principe 682 × 2560, en portrait).

Affiche le numéro de chaque écran pendant 3 secondes.

HWiNFO

Températures et consommations viennent de HWiNFO (gratuit), qui les transmet par sa fonction Gadget. Sans lui, ces widgets affichent « -- ».

Cette page se met à jour toute seule.

Configuration automatique

Arka Hyte coche lui-même dans HWiNFO les valeurs qu'il utilise (et celles des prochains widgets). HWiNFO est fermé puis relancé, Windows demande une autorisation d'administrateur ; vos réglages HWiNFO sont sauvegardés avant. Compter une à deux minutes. Il faut seulement que HWiNFO soit installé et que Enable reporting to Gadget soit coché (étape 2 ci-dessous).

Configuration manuelle

  1. Installez HWiNFO puis lancez-le en mode Capteurs seulement (Sensors-only).
  2. Dans la fenêtre des capteurs, ouvrez les paramètres (roue dentée), onglet HWiNFO Gadget, et cochez Enable reporting to Gadget.
  3. Dans la même liste, sélectionnez chaque valeur utile (température et consommation du CPU, horloge efficace moyenne et tension VDDCR_VDD du CPU, température, consommation, charge et mémoire du GPU) et cochez Report value in Gadget.
  4. Facultatif, pour la température des disques : dans le capteur S.M.A.R.T. de chaque disque, cochez Drive Temperature (Température du disque).
  5. Facultatif, pour les FPS en jeu : lancez un jeu, HWiNFO 64 bits ajoute alors un capteur PresentMon ; cochez sa valeur Framerate (Displayed) de la même façon. Aucun autre outil n'est nécessaire (le capteur RTSS de RivaTuner convient aussi).
  6. Pour qu'il démarre avec Windows : paramètres généraux de HWiNFO, cochez Auto Start et Minimize Sensors on Startup.

Capteurs

Choisissez la valeur HWiNFO de chaque widget, puis la température de chaque disque (proposée d'après le modèle du disque). Seules les valeurs cochées Report value in Gadget apparaissent dans les listes.

Aucune valeur reçue de HWiNFO : revenez à l'étape précédente.

Matériel

Noms affichés en tête des sections CPU et GPU.

Météo

La météo du jour peut s'afficher sous l'heure (données Open-Meteo, gratuites, sans compte). Cherchez votre ville puis choisissez-la dans la liste.

Vue jeu

Pendant une partie, l'écran du boîtier peut passer seul en vue jeu (FPS, carte graphique, processeur), puis revenir à la vue normale quand le jeu passe en arrière-plan (Alt+Tab, bureau). Un balayage sur l'écran change de vue à tout moment.

La vue jeu revient dès que le jeu repasse au premier plan. Un balayage vers la gauche ou la droite sur l'écran change de vue à tout moment ; pendant une partie, ce choix reste prioritaire jusqu'à la fin du jeu.

Jeux reconnus

La vue jeu s'ouvre pour les jeux que Windows reconnaît (liste de la Game Bar) et pour les jeux Unreal Engine ou Unity. Ajoutez ici ceux qui ne le sont pas, lancés au préalable.

Raccourcis

Actions à placer dans le dock de l'écran du boîtier, en plus des applications : une adresse web ou un script PowerShell. Elles apparaissent dans l'onglet Actions de l'éditeur du dock (appui long sur un bouton du dock), avec Verrouiller le PC, Mettre en veille et Capture d'écran.

Terminer

Les réglages sont enregistrés dans votre dossier de données, puis l'affichage du boîtier redémarre pour les appliquer. L'assistant reste accessible depuis le menu de l'icône.

Enregistrement impossible : voir le journal (menu de l'icône › Ouvrir le dossier des journaux).
